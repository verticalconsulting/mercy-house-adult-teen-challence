Read this before you open anything

Our website was rebuilt on a new platform. The measurement accounts — Google Analytics, Google Ads, Meta — all still exist and hold years of history. They just aren't connected to the new site yet.

Your job is to find those accounts and reconnect them. It is not to set up new ones.

If at any point a screen offers to create a new Analytics property, a new Ads conversion, or a new Meta pixel — that is the wrong button. Creating a new one starts our history back at zero, and it cannot be undone. When in doubt, stop and ask.

Before you begin, confirm you can sign in to all five: Google Analytics, Google Tag Manager, Google Ads, Google Search Console, and Meta Business Manager. If any login is missing, get it sorted first — you'll be switching between them constantly.

2

Create the Tag Manager container

~15 min

Tag Manager is the control panel that holds all our tracking in one place. From now on, tags get added there instead of in the website's code — which means you can make changes yourself without waiting on a developer.

This is the one thing you do create new. A container stores no history of its own, so a fresh one costs us nothing.

Write it down

Container IDGTM-
Hand off to a developer now — then wait

Send the developer two things: the container ID from this phase and the 9-digit Property ID from phase 1.

Nothing will track until they deploy that container ID to the website. Keep building tags in phases 3 and 4 while you wait, but do not start phase 5 until they confirm it's live — the tests cannot pass before then, and you'll waste an hour thinking you've made a mistake.

3

Teach Tag Manager what to listen for

~25 min

The website announces things as they happen, by name. A donation finishing has a name; a visitor moving to a new page has a name. Tag Manager can't react until you tell it which names to listen for. Those listeners are called triggers.

The five names the website uses
NameWhat just happened
spa_page_viewA visitor opened or moved to a page
donation_completeA donation finished paying
sponsorship_completeA student sponsorship finished paying
intake_payment_completeSomeone paid their own intake fee
intake_sponsored_completeSomeone paid an intake fee for another person
Exact spelling matters

These names are case-sensitive and contain underscores, never spaces. Donation_Complete and donation complete will both silently fail — no error message, just a tag that never fires. Copy and paste them.

The Analytics base tag

Don't skip the send_page_view setting

Without it, the first page of every visit gets counted twice — once automatically by this tag, once by the tag you build next. Every traffic number we report would be inflated, and it's very hard to spot after the fact.

6

Point the Ads conversions at the new tags

~20 min

Our Ads conversion actions used to be set off by the old website, which no longer exists. The actions themselves are still valuable — they carry years of history that Google's automatic bidding has learned from. You're changing what sets them off, not replacing them.

Never delete and recreate a conversion action

It looks like the tidy fix when an action shows as inactive. It isn't — it throws away the conversion history and resets the bidding model, which typically pushes our cost per donation up for weeks. Always repair the existing action.

7

Leave Search Console alone

~10 min

Almost nothing to do here, and that's the point. Our mercyhouseatc.com property has been collecting search history for years. It keeps working through a website rebuild because the address never changed.

Two buttons to stay away from

Don't add a new property for the site — the one we have is the one with the history.

Don't use the Change of Address tool. It's meant for a genuine move between addresses. The .org address was only ever a temporary test site, so pointing it at our real property gains us nothing while risking the records we already have.

Explain the gap in the data

~10 min

Between the old site coming down and today, nothing was being recorded. Anyone opening a report later will see traffic fall off a cliff and may reasonably panic. Leave them a note.

Worth saying out loud in your handover

Our page addresses changed with the rebuild — a page that used to be /about-us/ may now be /About. Total visits still compare fine against last year. Individual page comparisons do not, and no amount of setup can fix that. Flag it before someone builds a report on it.

Things that are not yours to undo

  • Creating a new Analytics property for the site
  • Deleting any Analytics property, including the leftover test one
  • Deleting or recreating a Google Ads conversion action
  • Creating a new Meta pixel
  • Adding a new Search Console property, or using Change of Address
  • Switching on any Google or Meta integration in the website's own hosting settings — it would double-count every donation

Any of these six wipes out history we can't get back. If a screen seems to be pushing you toward one, that's the moment to stop and ask.
