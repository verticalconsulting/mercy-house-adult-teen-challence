# Mercy House SEO + Analytics Cutover Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make every route on mercyhouseatc.com serve a unique, crawlable, correctly-canonicalised page, and measure every donation and lead conversion.

**Architecture:** The app stays a Vite + React SPA on Base44 static hosting. Per-route HTML for crawlers is delivered by Hado SEO, a DNS-level prerendering proxy that snapshots the rendered React output — so per-route uniqueness must be correct *in the app*, and Hado only makes it visible without JS. A single canonical-map module becomes the source of truth from which the SEO metadata, the sitemap, the router and the 301 table all derive, so the four cannot drift. Analytics runs through one GTM container fed by `dataLayer` pushes.

**Tech Stack:** Vite 6, React 18 (JSX), react-router-dom 6, Base44 SDK (entities + Deno serverless functions), Vitest (added in Task 1), Hado SEO, GTM/GA4, Stripe + Virtuous.

**Spec:** The canonical map supplied by the user on 2026-09-28 (transcribed verbatim into `src/lib/canonical-map.js` in Task 1) plus the task list in that same message. There is no separate spec file — the canonical map *is* the spec for routing and SEO.

## Global Constraints

- Base URL is `https://mercyhouseatc.com`, read from `import.meta.env.VITE_SITE_URL` with that value as the fallback default. Never hardcode the origin anywhere else.
- `mercyhouseatc.org` is legacy. It may appear in exactly one place in the codebase: the 301 redirect map. Nowhere else.
- Apex domain only — no `www.` in any canonical, sitemap `<loc>`, `og:url`, `twitter:url`, or schema `url`/`@id`.
- For a given page the same URL must appear in all five places: `<link rel="canonical">`, sitemap `<loc>`, `og:url`, `twitter:url`, schema `url`/`@id`.
- Organisation schema type is `NonprofitOrganization`. Address is 1110 Mary St, Georgetown, MS 39078, US. Phone is `+1-601-720-3718`.
- `src/pages.config.js` is auto-generated by Base44 — only `mainPage` is editable. Never add imports there.
- `src/components/ui/` is vendored shadcn/ui, excluded from lint and typecheck. Do not hand-edit.
- App code is JSX, not TSX. Only `src/utils/index.ts` and `base44/functions/**` are TypeScript.
- Noindex pages must stay crawlable. Use `X-Robots-Tag` / `<meta name="robots">`, never `Disallow` in robots.txt — a disallowed page can never be crawled to discover its noindex.
- Commit after every task. Do not squash tasks together.

## Review Focus

Failure modes the spec implies but that no single feature task naturally exercises. Each names the test that pins it and the task that owns that test.

1. **A route exists in the app but not in the canonical map, or vice versa** — a new page ships with no title, or the sitemap advertises a 404. Pinned by the bidirectional parity test in Task 1.
2. **Two routes share a title or description** — the classic SPA failure, and precisely what the `Googlebot: https://mercyhouseatc.org/` column in the spec shows happening today on every row. Pinned by the uniqueness tests in Task 1.
3. **A noindex page leaks into the sitemap** — a sitemap `<loc>` is a positive indexing signal that directly contradicts a noindex directive. Pinned by the sitemap-excludes-noindex test in Task 4.
4. **`SeoManager` silently no-ops on an unmapped path** — it currently calls `useDocumentMeta({title: null})`, and the hook early-returns on a falsy title, leaving the *previous* route's title in the document. A visitor navigating A→B sees B's content under A's title. Pinned by the stale-title test in Task 3.
5. **The prerendered snapshot is captured before React Query resolves** — testimony and blog pages fetch from Base44, so Hado could cache a skeleton with an empty `<h1>`. Pinned by the rendered-HTML assertions in Task 10.

- [ ] **Step 5: Add `resolveSeo` to `src/lib/seo.js`**

At the end of the file, after the `pageSeo` export:

```js
/**
 * Look up the SEO entry for a pathname.
 *
 * Unmapped paths get a self-canonicalising noindex fallback rather than
 * `null`. Returning null previously let <SeoManager> no-op, which left the
 * *previous* route's <title> and canonical in the document during client-side
 * navigation — so an unmapped page reported itself as whatever the visitor
 * looked at last.
 */
export function resolveSeo(pathname) {
  let path = pathname || '/';
  if (path.length > 1 && path.endsWith('/')) path = path.slice(0, -1);

  const entry = pageSeo[path];
  if (entry) return entry;

  return {
    title: 'Mercy House Adult & Teen Challenge | Faith-Based Recovery in Mississippi',
    description:
      'Mercy House Adult & Teen Challenge is a Christ-centered residential recovery ministry for men and women in Georgetown and Learned, Mississippi.',
    path,
    noindex: true,
  };
}
```

```js
import { INDEXABLE_PATHS } from './canonical-map';

function escapeXml(value) {
  return value
    .replace(/&/g, '&amp;')
    .replace(/</g, '&lt;')
    .replace(/>/g, '&gt;')
    .replace(/"/g, '&quot;')
    .replace(/'/g, '&apos;');
}

/**
 * Build sitemap XML for `origin`.
 *
 * Derived from the canonical map rather than from the router, so a page can
 * never be advertised to Google without also having a title, a description
 * and a self-canonical. `lastmod` is deliberately omitted: a build-time
 * timestamp on every URL tells Google every page changed on every deploy,
 * which trains it to ignore the field.
 */
export function buildSitemap(origin, paths = INDEXABLE_PATHS) {
  const urls = paths
    .map((path) => {
      const loc = escapeXml(path === '/' ? `${origin}/` : `${origin}${path}`);
      return `  <url>\n    <loc>${loc}</loc>\n  </url>`;
    })
    .join('\n');

  return `<?xml version="1.0" encoding="UTF-8"?>\n<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">\n${urls}\n</urlset>\n`;
}
```

The monthly gift happens inside a cross-origin Virtuous iframe. The browser cannot see it complete, so this conversion must be reported from the server via the GA4 Measurement Protocol when Virtuous confirms the recurring gift.

- [ ] **Step 1: Write the handler**

```ts
/**
 * Virtuous recurring-gift webhook -> GA4 Measurement Protocol.
 *
 * Why server-side: /donate/monthly embeds a Virtuous-hosted iframe. It is
 * cross-origin and there is no post-payment redirect back to this site, so
 * the browser has no way to observe a completed monthly gift. Virtuous is the
 * only party that knows it happened.
 *
 * `client_id` is a synthetic per-gift id, not the donor's GA client id, which
 * we never see. GA4 therefore attributes these as new sessions rather than
 * joining them to the on-site journey; that is a known and accepted limit of
 * measuring an iframed processor.
 */
import { verifyAutomationSecret } from '../../shared/security.ts';

const GA4_ENDPOINT = 'https://www.google-analytics.com/mp/collect';

Deno.serve(async (req: Request) => {
  if (req.method !== 'POST') return new Response('Method not allowed', { status: 405 });

  const body = await req.json();
  if (!verifyAutomationSecret(body)) return new Response('Unauthorized', { status: 401 });

  const measurementId = Deno.env.get('GA4_MEASUREMENT_ID');
  const apiSecret = Deno.env.get('GA4_API_SECRET');
  if (!measurementId || !apiSecret) {
    console.error('GA4 credentials missing; monthly gift not reported');
    return new Response('Not configured', { status: 500 });
  }

  const giftId = String(body.giftId ?? body.id ?? crypto.randomUUID());
  const amount = Number(body.amount ?? 0);

  const res = await fetch(
    `${GA4_ENDPOINT}?measurement_id=${encodeURIComponent(measurementId)}&api_secret=${encodeURIComponent(apiSecret)}`,
    {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        client_id: `virtuous.${giftId}`,
        non_personalized_ads: false,
        events: [
          {
            name: 'monthly_gift_complete',
            params: {
              currency: 'USD',
              value: amount,
              transaction_id: giftId,
              checkout_type: 'monthly',
            },
          },
        ],
      }),
    }
  );

  if (!res.ok) {
    console.error('GA4 Measurement Protocol rejected the event', res.status, await res.text());
    return new Response('Upstream error', { status: 502 });
  }

  return new Response(JSON.stringify({ ok: true }), {
    headers: { 'Content-Type': 'application/json' },
  });
});
```

- [ ] **Step 2: Create `scripts/verify-rendered-seo.mjs`**

```js
/**
 * Fetch every canonical route as Googlebot and assert the page that comes
 * back is actually that page.
 *
 * This is the acceptance test for the prerender layer. Run against the live
 * origin after the Hado DNS change: if Hado is serving snapshots correctly,
 * every route returns its own title, description, H1 and self-canonical with
 * no JavaScript executed. Before the DNS change every route returns the
 * shell's homepage canonical, which is exactly the failure the audit found.
 */
import { CANONICAL_ROUTES, INDEXABLE_PATHS, LEGACY_REDIRECTS } from '../src/lib/canonical-map.js';

const ORIGIN = process.env.VERIFY_ORIGIN || 'https://mercyhouseatc.com';
// Below this much rendered text a page is the templated shell, not a page.
const MIN_BODY_WORDS = 120;
const UA =
  'Mozilla/5.0 (compatible; Googlebot/2.1; +http://www.google.com/bot.html)';

const failures = [];
const titles = new Map();
const bodies = new Map();

function fail(path, message) {
  failures.push(`${path}: ${message}`);
}

function extract(html, re) {
  const m = html.match(re);
  return m ? m[1].trim() : null;
}

for (const { path, noindex } of CANONICAL_ROUTES) {
  const url = path === '/' ? `${ORIGIN}/` : `${ORIGIN}${path}`;
  let res;
  try {
    res = await fetch(url, { headers: { 'User-Agent': UA }, redirect: 'manual' });
  } catch (err) {
    fail(path, `request failed: ${err.message}`);
    continue;
  }

  if (res.status !== 200) {
    fail(path, `expected 200, got ${res.status}`);
    continue;
  }

  const html = await res.text();

  const title = extract(html, /<title[^>]*>([^<]*)<\/title>/i);
  const desc = extract(html, /<meta[^>]+name=["']description["'][^>]+content=["']([^"']*)["']/i);
  const canonical = extract(html, /<link[^>]+rel=["']canonical["'][^>]+href=["']([^"']*)["']/i);
  const ogUrl = extract(html, /<meta[^>]+property=["']og:url["'][^>]+content=["']([^"']*)["']/i);
  const h1 = extract(html, /<h1[^>]*>([\s\S]*?)<\/h1>/i);

  if (!title) fail(path, 'no <title>');
  if (!desc) fail(path, 'no meta description');
  if (!h1 || !h1.replace(/<[^>]*>/g, '').trim()) {
    // Review Focus 5: an empty H1 means the snapshot was taken before React
    // Query resolved, so Hado cached a loading skeleton.
    fail(path, 'no rendered <h1> — snapshot likely captured before data loaded');
  }

  const h1Count = (html.match(/<h1[\b>]/gi) || []).length;
  if (h1Count > 1) fail(path, `${h1Count} <h1> elements, expected 1`);

  // "Core body copy for every page, not the templated shell." Strip the nav
  // and footer that every page shares, then require enough words left over
  // that this page says something of its own. A prerendered shell sails past
  // the title and canonical checks but has almost no unique text.
  const body = html
    .replace(/<script[\s\S]*?<\/script>/gi, '')
    .replace(/<style[\s\S]*?<\/style>/gi, '')
    .replace(/<nav[\s\S]*?<\/nav>/gi, '')
    .replace(/<footer[\s\S]*?<\/footer>/gi, '')
    .replace(/<[^>]+>/g, ' ')
    .replace(/\s+/g, ' ')
    .trim();
  const wordCount = body ? body.split(' ').length : 0;
  if (wordCount < MIN_BODY_WORDS) {
    fail(path, `only ${wordCount} words of body copy (min ${MIN_BODY_WORDS}) — likely the shell`);
  }
  const bodyKey = body.slice(0, 600);
  if (bodies.has(bodyKey)) fail(path, `body copy is identical to ${bodies.get(bodyKey)}`);
  else bodies.set(bodyKey, path);

  if (canonical !== url) fail(path, `canonical is ${canonical}, expected ${url}`);
  if (ogUrl && ogUrl !== url) fail(path, `og:url is ${ogUrl}, expected ${url}`);

  if (/mercyhouseatc\.org/.test(html)) fail(path, 'references the legacy .org domain');
  if (/mercyhouseworks\.org/.test(html)) fail(path, 'references mercyhouseworks.org');
  if (/www\.mercyhouseatc\.com/.test(canonical || '')) fail(path, 'canonical uses the www subdomain');

  const robots = extract(html, /<meta[^>]+name=["']robots["'][^>]+content=["']([^"']*)["']/i) || '';
  const xRobots = res.headers.get('x-robots-tag') || '';
  const isNoindexed = /noindex/i.test(robots) || /noindex/i.test(xRobots);
  if (noindex && !isNoindexed) fail(path, 'should be noindex but is indexable');
  if (!noindex && isNoindexed) fail(path, 'is noindexed but should be indexable');

  if (title) {
    if (titles.has(title)) fail(path, `duplicate title, shared with ${titles.get(title)}`);
    else titles.set(title, path);
  }
}

// Legacy URLs must 301 to their replacement, not 404 and not chain.
for (const [from, to] of Object.entries(LEGACY_REDIRECTS)) {
  const res = await fetch(`${ORIGIN}${from}`, {
    headers: { 'User-Agent': UA },
    redirect: 'manual',
  });
  if (res.status !== 301) {
    fail(from, `expected 301, got ${res.status}`);
    continue;
  }
  const location = res.headers.get('location') || '';
  const expected = `${ORIGIN}${to}`;
  if (location !== expected) fail(from, `301s to ${location}, expected ${expected}`);
}

// The sitemap must advertise exactly the indexable set.
const sitemap = await (await fetch(`${ORIGIN}/sitemap.xml`)).text();
for (const path of INDEXABLE_PATHS) {
  const loc = path === '/' ? `${ORIGIN}/` : `${ORIGIN}${path}`;
  if (!sitemap.includes(`<loc>${loc}</loc>`)) fail(path, 'missing from sitemap.xml');
}
for (const { path, noindex } of CANONICAL_ROUTES) {
  if (noindex && sitemap.includes(`<loc>${ORIGIN}${path}</loc>`)) {
    fail(path, 'noindex page is listed in sitemap.xml');
  }
}

if (failures.length) {
  console.error(`\n${failures.length} SEO verification failure(s):\n`);
  for (const f of failures) console.error(`  ✗ ${f}`);
  process.exit(1);
}
console.log(`✓ ${CANONICAL_ROUTES.length} routes verified against ${ORIGIN}`);
```
